Sudden death

Also: First miss eliminates

What it is

The second stage of a shoot-off, in which the first shooter to score a zero is eliminated.

In detail

If shooters are still tied after the 25-target shoot-off round, they shoot on in sudden death: the first to score a zero is eliminated, provided all have shot the same number of targets, and the last one left wins. In Sporting a double on report counts as a pair in sudden death, so one-zero equals zero-one. In Compak, after a draw, shooters take the single, then the first and second simultaneous doubles at each station, with the starting shooter alternating (Annex 5 gives the order for 2 and 3 shooters).

In Sporting™ and Compak® Sporting

Sporting™

Report double as a pair: one-zero = zero-one.

Compak® Sporting

Order per Annex 5: for 3 shooters 1-2-3, 2-3-1, 3-1-2.
