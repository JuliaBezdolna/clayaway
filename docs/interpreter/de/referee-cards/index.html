Verwarnungen, Karten und Strafen

Die FITASC-Strafen steigen stufenweise an. Mit der Anmeldung zu einem Wettkampf akzeptiert ein Schütze die Regeln und die Sanktionen. Der erste Regelverstoß bringt normalerweise eine Verwarnung, angezeigt mit der Gelben Karte. In Parcours de Chasse – Sporting™ ist ein klassisches Beispiel die Flintenhaltung: Ein Schaft über der Westenmarkierung oder eine Flinte, die angeschlagen wird, bevor die Scheibe erscheint, bringt eine mündliche Verwarnung und eine Gelbe Karte.

Eine Wiederholung auf demselben Layout (oder demselben Compak®) bringt die Rote Karte, und die Scheibe wird nach einer Tabelle gewertet: Null bei einer Einzelscheibe, Null und No Bird bei einer Doublette auf Schuss, Null und Null bei einer Simultan- oder Rafaledoublette. Dieselbe Skala gilt für das Schießen auf ein angesagtes No Bird und in Sporting™ für das Überschreiten von fünfzehn Sekunden zwischen den Scheiben. Im Compak® Sporting liegt die Grenze bei zehn Sekunden für den Abruf.

Auch Coaching während eines Wettkampfs wird bestraft: Der Schütze erhält eine Gelbe Karte, Wiederholungen führen zu weiteren Sanktionen, und der Schiedsrichter verweist die Person, die gecoacht hat, aus dem Schießbereich. Für einen Dolmetscher ist das die wichtigste Karte im ganzen Regelwerk.

Bei wiederholten Verstößen, Weigerung, der Anweisung zu folgen, oder Beeinflussungsversuchen gegenüber einem Schiedsrichter kann die Jury eine Scheibe, eine ganze Runde von 25 abziehen oder den Schützen ausschließen. Das Werfen einer Flinte, Beleidigung oder Gewalt und das absichtliche Schießen auf lebende Tiere können den sofortigen Ausschluss bedeuten. Ein Ausschluss wird von der FITASC fünf Jahre lang festgehalten und bringt keine Rückerstattung. Übersetzen Sie „warning“, „yellow card“ und „red card“ wörtlich, ruhig und sofort.

Das Wichtigste
  • Erster Verstoß: Verwarnung mit Gelber Karte
  • Wiederholung auf demselben Layout oder Compak®: Rote Karte + Wertung der Scheibe nach Tabelle
  • Coaching im Wettkampf: Gelbe Karte für den Schützen, Trainer wird verwiesen
  • Skala der Jury: eine Scheibe, eine Runde oder Ausschluss
  • Ausschluss: 5 Jahre festgehalten, keine Rückerstattung

Der Trainer sagt

“Warning — your stock was above the line.”
Sporting™: Die Flinte war zu hoch, bevor die Scheibe erschien; beim nächsten Mal auf diesem Layout kostet es die Scheibe.
Verwarnung – Ihr Schaft war über der Markierung.
“That’s a yellow card.”
Eine offizielle erste Verwarnung; sie wird festgehalten.
Das ist eine Gelbe Karte.
“Red card — the target is zero.”
Ein wiederholter Verstoß: Die Scheibe wird als verloren gewertet.
Rote Karte – die Scheibe ist Null.
“You’re over time.”
Der Schütze hat länger gebraucht als erlaubt (15 s in Sporting™, 10 s für den Abruf im Compak®).
Sie haben die Zeit überschritten.
“Sir, please leave the shooting area.”
Der Schiedsrichter verweist jemanden, zum Beispiel eine Person, die beim Coaching ertappt wurde.
Bitte verlassen Sie den Schießbereich.

Testen Sie sich

Sporting™: Nach einer Gelben Karte für eine angeschlagene Flinte schlägt der Schütze auf demselben Layout bei einer Einzelscheibe wieder zu früh an. Was ist die Folge?
  1. Eine weitere Verwarnung
  2. Rote Karte und die Scheibe ist Null
  3. No Bird
  4. Sofortiger Ausschluss
Richtig!

Rote Karte und die Scheibe ist Null — Nach der ersten Verwarnung bringt ein weiterer Verstoß auf demselben Layout die Rote Karte; bei einer Einzelscheibe ist die Scheibe Null.

Der Schiedsrichter sieht, wie ein Trainer einem Schützen während eines Wettkampfs Ratschläge gibt. Was sagen die Regeln?
  1. Nichts, Coaching ist zwischen den Ständen erlaubt
  2. Der Trainer erhält eine Rote Karte
  3. Der Schütze erhält eine Gelbe Karte, und der Trainer wird aus dem Schießbereich verwiesen
  4. Die Runde wird annulliert
Richtig!

Der Schütze erhält eine Gelbe Karte, und der Trainer wird aus dem Schießbereich verwiesen — Beide Regelwerke geben dem Teilnehmer eine Gelbe Karte und lassen den Schiedsrichter die coachende Person aus dem Schießbereich verweisen.

Welche dieser Strafen kann die Jury nach der Strafskala NICHT verhängen?
  1. Abzug einer Scheibe
  2. Abzug einer Runde von 25
  3. Ausschluss
  4. Eine Geldstrafe, die an den Schiedsrichter gezahlt wird
Richtig!

Eine Geldstrafe, die an den Schiedsrichter gezahlt wird — Die Skala der Jury umfasst den Abzug einer Scheibe, den Abzug einer Runde oder den Ausschluss; eine Geldstrafe an den Schiedsrichter gibt es nicht.
