Einzelscheiben und Doubletten im Compak®

Compak® Sporting verwendet dieselben Wörter wie Parcours de Chasse – Sporting™, aber seine Doubletten folgen anderen Regeln. Ein Dolmetscher, der die Sporting™-Regeln überträgt, gibt falsche Antworten.

Einzelscheiben: Jede Einzelscheibe muss von jeder der fünf Positionen zwei Schüsse ermöglichen, der zweite Lauf ist also eine legitime zweite Chance.

Das Compak®-Regelwerk kennt zwei Arten von Doubletten: auf Schuss (der Abruf löst die erste Scheibe aus, der Schuss die zweite; eine oder zwei Maschinen) und simultan (zwei Scheiben auf einen Abruf, immer aus zwei verschiedenen Maschinen, in beliebiger Reihenfolge beschossen). Eine Rafale gibt es nicht.

Der entscheidende Unterschied: Bei einer Compak®-Doublette darf auf jede Scheibe nur eine Patrone abgegeben werden. Beide Schüsse auf die erste Scheibe abzugeben ist verboten, und der Kurzleitfaden für Schiedsrichter wertet einen absichtlichen Doppelschuss auf eine Scheibe als Null und Null. In Sporting™ dürfen beide Patronen auf eine Scheibe abgegeben werden.

Zwei Scheiben mit einem Schuss: Bei einer Doublette auf Schuss zählt das erste Ergebnis, die zweite ist ein No Bird, und die Doublette wird wiederholt. Bei einer Simultandoublette ist es ein No Bird ohne Wertung, und die Doublette wird wiederholt; beim zweiten Mal ebenso; beim dritten Mal Null und Null. In Sporting™ wird derselbe Schuss einfach als Treffer und Treffer gewertet.

Irreguläre Scheiben: Ist die erste Scheibe einer Doublette auf Schuss oder eine der beiden Scheiben einer Simultandoublette irregulär, wird eine neue Doublette geworfen. Ist die zweite Scheibe einer Doublette auf Schuss irregulär oder wird sie durch die erste zerstört, zählt das erste Ergebnis, und die Doublette wird wiederholt.

Das Wichtigste
  • Nur zwei Doublettenarten: auf Schuss und simultan; keine Rafale.
  • Eine Patrone pro Scheibe in einer Doublette; beide auf eine Scheibe = Null und Null (Kurzleitfaden).
  • Doublette auf Schuss, zwei mit einem Schuss: erstes Ergebnis bleibt, zweite No Bird, Doublette wird wiederholt.
  • Simultan, zwei mit einem Schuss: zweimal No Bird, beim dritten Mal Null und Null.

Testen Sie sich

Simultandoublette im Compak®. Ein Schuss zerstört beide Scheiben; es passiert zum ersten Mal. Entscheidung?
  1. Treffer und Treffer
  2. No Bird, keine Wertung, die Doublette wird wiederholt
  3. Treffer und No Bird
  4. Null und Null
Richtig!

No Bird, keine Wertung, die Doublette wird wiederholt — Im Compak® ist eine mit einem Schuss zerstörte Simultandoublette beim ersten und zweiten Mal ein No Bird und beim dritten Mal Null und Null.

Doublette auf Schuss im Compak®. Ein Schuss zerstört beide Scheiben. Entscheidung?
  1. Treffer und Treffer
  2. Null und Null
  3. Das erste Ergebnis zählt, die zweite ist ein No Bird, und die Doublette wird wiederholt
  4. No Bird, keine Wertung
Richtig!

Das erste Ergebnis zählt, die zweite ist ein No Bird, und die Doublette wird wiederholt — Bei einer Doublette auf Schuss wird das Ergebnis der ersten Scheibe festgehalten, und die Doublette wird erneut geschossen, um die zweite zu werten.

Bei einer Compak®-Doublette fehlt ein Schütze die erste Scheibe und gibt absichtlich auch die zweite Patrone auf sie ab. Wie wertet der Kurzleitfaden für Schiedsrichter das?
  1. Null und Null
  2. Es ist erlaubt, wie in Sporting™
  3. Die Doublette wird wiederholt
  4. Nur der zweite Schuss zählt
Richtig!

Null und Null — Bei einer Compak®-Doublette ist nur eine Patrone pro Scheibe erlaubt; ein absichtlicher Doppelschuss auf eine Scheibe ist Null und Null.
