Einzelscheiben und Doubletten

Eine Einzelscheibe ist eine Scheibe aus einer Maschine. In Parcours de Chasse – Sporting™ darf der Schütze zwei Patronen auf sie abgeben, ein Fehlschuss mit dem ersten Lauf kann also mit dem zweiten noch gerettet werden. Jede Einzelscheibe muss Zeit für zwei Schüsse lassen.

Eine Doublette sind zwei Scheiben, und der Schütze hat dafür nur zwei Patronen; beide dürfen auf dieselbe Scheibe abgegeben werden. Es gibt drei Arten. Auf Schuss: Die zweite Scheibe kommt 0 bis 3 Sekunden nach dem Schuss auf die erste, ausgelöst durch diesen Schuss. Simultan: Beide starten im selben Moment, aus einer oder zwei Maschinen. Rafale: zwei Scheiben aus derselben Maschine auf derselben Linie, die zweite so schnell, wie die Maschine nachlädt. Bei Simultan- und Rafaledoubletten dürfen die Scheiben in beliebiger Reihenfolge beschossen werden. Doubletten verwenden nur Scheiben, die vom selben Stand bereits als Einzelscheiben gezeigt wurden.

Entscheidungen, die der Schiedsrichter oft treffen muss: Zerstört ein Schuss beide Scheiben einer beliebigen Doublette, zählen beide, Treffer und Treffer. Schießt der Schütze ohne triftigen Grund nicht auf eine Rafale- oder Simultandoublette, ist es Null und Null.

Bei einer Doublette auf Schuss bedeutet eine irreguläre erste Scheibe, dass die Doublette wiederholt wird; zerstören die erste Scheibe oder ihre Teile die zweite vor dem zweiten Schuss oder ist die zweite irregulär, wird die Doublette wiederholt und das erste Ergebnis beibehalten. Bei Simultan- und Rafaledoubletten bedeutet eine irreguläre Scheibe eine Wiederholung ohne eingetragenes Ergebnis.

Tipp: Geben Sie das Ergebnis einer Doublette als Paar weiter, in der Reihenfolge des Schiedsrichters.

Das Wichtigste
  • Einzelscheibe: zwei Patronen erlaubt.
  • Doublette: insgesamt zwei Patronen, beide dürfen auf eine Scheibe; Arten: auf Schuss, simultan, Rafale.
  • Ein Schuss zerstört beide Scheiben: Treffer und Treffer.
  • Kein Schuss auf eine Simultan- oder Rafaledoublette ohne Grund: Null und Null.

Der Trainer sagt

“Report pair: the second comes on your shot.”
Trainer: Die zweite Scheibe wird durch den Schuss auf die erste ausgelöst.
Doublette auf Schuss: Die zweite kommt auf Ihren Schuss.
“On the rafale, take either one first.”
Bei einer Rafaledoublette ist die Reihenfolge frei.
Bei der Rafale nehmen Sie zuerst, welche Sie wollen.
“One and one.”
Schiedsrichter: Beide Scheiben der Doublette sind Treffer.
Treffer und Treffer.
“No Bird, repeat the double.”
Irreguläre Scheibe; die Doublette wird neu geworfen.
No Bird, die Doublette wird wiederholt.

Testen Sie sich

Simultandoublette. Ein Schuss zerstört beide Scheiben. Wie entscheidet der Schiedsrichter?
  1. Treffer und Treffer
  2. Treffer und No Bird
  3. No Bird, die Doublette wird wiederholt
  4. Treffer und Null
Richtig!

Treffer und Treffer — In Sporting™ werden zwei mit einem Schuss zerstörte Scheiben jeder Doublette als Treffer und Treffer gewertet (Compak® Sporting ist anders).

Doublette auf Schuss. Der Schütze trifft die erste Scheibe, und ein Stück davon zerschlägt die zweite vor dem zweiten Schuss. Entscheidung?
  1. Treffer und Treffer
  2. Die Doublette wird wiederholt, und das erste Ergebnis wird beibehalten
  3. Null auf die zweite Scheibe
  4. Treffer und Null
Richtig!

Die Doublette wird wiederholt, und das erste Ergebnis wird beibehalten — Zerstören die erste Scheibe oder ihre Teile die zweite vor dem zweiten Schuss, wird die Doublette wiederholt, und das erste Ergebnis bleibt bestehen.

Rafaledoublette. Beide Scheiben fliegen korrekt, aber der Schütze senkt die Flinte und schießt auf keine, ohne triftigen Grund. Entscheidung?
  1. No Bird
  2. Null und No Bird
  3. Nur eine Gelbe Karte
  4. Null und Null
Richtig!

Null und Null — Eine korrekte Scheibe, auf die ohne triftigen Grund nicht geschossen wird, ist verloren; bei einer Rafale- oder Simultandoublette heißt das Null und Null.
