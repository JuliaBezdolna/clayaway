Scheiben, keine Vögel: was dieser Sport ist

Das Wurfscheibenschießen ist ein Sport, bei dem ein Schütze kleine fliegende Scheiben mit einer Flinte zerschießt. Die Scheibe heißt Wurfscheibe oder kurz Scheibe (englisch target oder clay); Schützen nennen sie oft Taube (englisch bird), aber niemand schießt auf lebende Tiere. Die FITASC-Regeln sagen klar, dass das Schießen auf lebende Tiere nicht erlaubt ist, und Sicherheit und Rücksicht auf die Umwelt stehen an erster Stelle.

Eine Maschine, die Wurfmaschine (trap), wirft jede Scheibe. Ihr Weg durch die Luft (oder über den Boden) ist die Flugbahn. Die Waffe ist eine Flinte mit glattem Lauf: Sie verschießt eine Patrone voller kleiner Kugeln, des Schrots, die sich zu einer kleinen Wolke ausbreiten. Deshalb richtet der Schütze die Flinte dorthin, wohin die Scheibe fliegt, nicht dorthin, wo sie gerade ist.

Dieser Kurs behandelt zwei Disziplinen des internationalen Verbands FITASC. Parcours de Chasse – Sporting™ (kurz Sporting™) ahmt die Jagd nach: Die Maschinen sind in Feldern und Wäldern versteckt, und die Scheiben fliegen wie Rebhuhn, Ente oder Fasan oder rollen wie ein Hase. Compak® Sporting ist die kompakte Version: dieselbe Vielfalt an Scheiben, aber auf einem kleinen Feld mit fünf Schießpositionen in einer Reihe und sechs Maschinen.

Sie werden auch von Trap und Skeet hören. Das sind andere Disziplinen mit festen, sich wiederholenden Flugbahnen; Olympisch Trap und Skeet gehören zu einem anderen Verband. Vermischen Sie deren Regeln nicht mit Sporting™ oder Compak® Sporting.

Ein Treffer ist sofort sichtbar: Die Scheibe zerbricht oder zumindest fliegt ein sichtbares Teil ab. Diese Klarheit macht den Sport leicht anzusehen und für Sie vom ersten Tag an leicht zu verfolgen.

Das Wichtigste
  • Geschossen wird auf Wurfscheiben, die von Maschinen geworfen werden, nie auf lebende Tiere.
  • Eine Flinte verschießt eine Wolke kleiner Kugeln (Schrot), also zielt der Schütze vor die Scheibe.
  • Sporting™ ahmt die Jagd im natürlichen Gelände nach; Compak® Sporting ist seine kompakte Version auf einem Feld.
  • Trap und Skeet sind andere Disziplinen mit eigenen Regeln.

Der Trainer sagt

“Watch this bird off trap B.”
„Bird“ ist eine Scheibe, kein echter Vogel; Maschine B ist die mit B gekennzeichnete Maschine.
Schauen Sie sich diese Taube aus Maschine B an.
“Today we walk the Sporting course, tomorrow it's Compak.”
Zwei verschiedene Disziplinen an zwei verschiedenen Tagen.
Heute gehen wir den Sporting-Parcours, morgen ist Compak dran.
“Point it, don't aim it.”
Eine Flinte wird mit beiden Augen auf der Scheibe geschwenkt und gerichtet, nicht wie eine Büchse gezielt.
Richten, nicht zielen.

Testen Sie sich

Ein Trainer sagt „Watch the next bird.“ Was werden Sie sehen?
  1. Eine lebende Taube, die aus einer Kiste freigelassen wird
  2. Eine Wurfscheibe, die von einer Maschine geworfen wird
  3. Eine vogelförmige Papierscheibe auf einer Tafel
  4. Eine Drohne
Richtig!

Eine Wurfscheibe, die von einer Maschine geworfen wird — „Bird“ ist der Jargon der Schützen für eine Wurfscheibe; die FITASC-Regeln verbieten das Schießen auf lebende Tiere.

Was verschießt eine Flinte?
  1. Ein einzelnes Geschoss
  2. Einen kleinen pfeilartigen Bolzen
  3. Eine Wolke kleiner Kugeln (Schrot)
  4. Eine mit Farbe gefüllte Kugel
Richtig!

Eine Wolke kleiner Kugeln (Schrot) — Der Schrot verlässt die Mündung als kleine Wolke von Kugeln, also zielt der Schütze vor die fliegende Scheibe.

Welche Aussage über Compak® Sporting ist richtig?
  1. Eine kompakte Version auf einem Feld, Positionen in einer Reihe
  2. Es ist die olympische Version der Disziplin Skeet
  3. Es wird nur auf lebendes Federwild im Feld geschossen
  4. Es verwendet eine einzige Maschine und eine einzige Position
Richtig!

Eine kompakte Version auf einem Feld, Positionen in einer Reihe — Compak® Sporting bringt Scheiben im Stil von Sporting™ auf ein kleines Feld mit fünf Positionen und sechs Maschinen.
