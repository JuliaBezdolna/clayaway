Reading the target menu

The target menu («меню») is the board at the stand that tells the shooter what is coming. Shooters really say 'menu', so keep the word.

In Parcours de Chasse – Sporting™ the menu lists the traps in shooting order and must show any special targets: 90 mm, 70 mm, 60 mm, battue or rabbit. Referees check beforehand that the machines match the menu. A layout gives 15 singles and 5 doubles, and the doubles may only use targets already shown as singles from the same stand. The squad shoots the singles first, then the doubles.

A double is marked with its type: on report (the second target leaves on the sound of the first shot), simultaneous (both together) or rafale (two from the same trap, one after the other; Sporting™ only). Menus look different from ground to ground, so read the words, not just the letters. Example for a stand with three traps: singles A, B, C; doubles A + B simultaneous and C + C rafale (at such a stand two doubles on report are not allowed).

In Compak® Sporting a menu is shown at each of the five stations. Each station has five targets: five singles, three singles and a double, or one single and two doubles. The type of double is the same at all five stations of a Compak, and the first target of each double is the last target of the previous station. FITASC offers 40 ready-made menus for competitions.

Before your shooter steps up, read the menu aloud to them in their language, letter by letter: 'A, then F, then B, then the pair C and E on report.'

Key points
  • Keep the word 'menu'.
  • Sporting™ menu: traps in order plus special targets (90, 70, 60 mm, battue, rabbit).
  • 15 singles + 5 doubles; doubles use targets already shown as singles; singles first.
  • Doubles: on report, simultaneous, rafale (Sporting™ only).
  • Compak®: five targets per station, same double type on all stations, each double starts with the previous station's last target.

The coach says

“Read the menu: on station three you have A, then F, then B, then the pair C and E on report.”
Station 3: three singles, then a double on report; five targets in all.
“Same traps, new menu — don't shoot from memory.”
The order has changed since the last round.
“Three singles, then a simo pair.”
'Simo' is short for a simultaneous double.

Check yourself

Which special targets must a Sporting™ menu show?
  1. Only the colours of the targets
  2. 90 mm, 70 mm, 60 mm, battue or rabbit
  3. Only rabbits and battues
  4. None; the referee announces them
Correct!

90 mm, 70 mm, 60 mm, battue or rabbit — The menu must list the traps in order and any special target types.

In Compak® Sporting, with which target does each double start?
  1. Always trap A
  2. A target never seen before
  3. The last target shot at the previous station
  4. Any target the shooter chooses
Correct!

The last target shot at the previous station — The doubles chain across stations: each begins with the last target of the station before.

Which type of double exists only in Sporting™?
  1. Rafale
  2. On report
  3. Simultaneous
  4. None
Correct!

Rafale — Compak® doubles are on report or simultaneous; rafale is a Sporting™ double.
