Singles and doubles in Compak®

Compak® Sporting uses the same words as Parcours de Chasse – Sporting™, but its doubles follow different rules. An interpreter who carries the Sporting™ rules over will give wrong answers.

Singles: every single must allow two shots from each of the five stations, so the second barrel is a legitimate second chance.

The Compak® rulebook defines two kinds of double: on report (the call releases the first target, the shot releases the second; one or two traps) and simultaneous (two targets on one call, always from two different traps, taken in either order). There is no rafale.

The key difference: in a Compak® double only one cartridge may be fired at each target. Firing both shots at the first target is prohibited, and the referees' quick guide scores a deliberate double shot at one target zero and zero. In Sporting™ both cartridges may go at one target.

Two targets with one shot: on a double on report the first result stands, the second is a No Bird, and the double is shot again. On a simultaneous double it is a No Bird with nothing scored and the double repeated; the same the second time; the third time it is zero and zero. In Sporting™ the same shot simply scores one and one.

Irregular targets: if the first target of a report pair, or either target of a simultaneous double, is irregular, a new double is thrown. If the second target of a report pair is irregular or broken by the first, the first result stands and the double is repeated.

Key points
  • Two kinds of double only: on report and simultaneous; no rafale.
  • One cartridge per target in a double; both at one target = zero and zero (quick guide).
  • Report pair, two with one shot: first result kept, second No Bird, double repeated.
  • Simultaneous, two with one shot: No Bird twice, zero and zero the third time.

The coach says

“One shot per bird on the pairs here.”
Coach: in Compak® each target of a double gets only one cartridge.
“Both with one shot. No Bird, shoot the double again.”
Referee on a simultaneous double: nothing scored, repeat.
“Choose your order on the show.”
Coach: decide which simultaneous target to take first while watching the presentation.
“Zero, zero.”
Referee: neither target of the double is scored.

Check yourself

Simultaneous double in Compak®. One shot breaks both targets; it is the first time this has happened. Decision?
  1. One and one
  2. No Bird, nothing scored, the double is repeated
  3. One and No Bird
  4. Zero and zero
Correct!

No Bird, nothing scored, the double is repeated — In Compak® a simultaneous double broken with one shot is a No Bird the first and second time, and zero and zero the third time.

Double on report in Compak®. One shot breaks both targets. Decision?
  1. One and one
  2. Zero and zero
  3. The first result stands, the second is a No Bird, and the double is repeated
  4. No Bird, nothing scored
Correct!

The first result stands, the second is a No Bird, and the double is repeated — On a report pair the first target's result is recorded and the double is shot again to score the second.

In a Compak® double, a shooter misses the first target and deliberately fires the second cartridge at it as well. How does the referees' quick guide score it?
  1. Zero and zero
  2. It is allowed, as in Sporting™
  3. The double is repeated
  4. Only the second shot counts
Correct!

Zero and zero — Only one cartridge per target is allowed in a Compak® double; a deliberate double shot at one target is zero and zero.
