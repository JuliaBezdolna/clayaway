La position : les pieds vers le point de casse

La position (stance) est la façon dont le tireur se tient avant le tir. L'espace est réduit : en Parcours de Chasse – Sporting™, le poste de tir est un carré ou un cercle de 1 m, et les deux pieds doivent s'y trouver avant que le tireur appelle le plateau. En Compak® Sporting, chaque pas de tir est un carré de 1 m équipé d'un limiteur d'angle de tir, un cadre qui empêche le tireur d'avancer et limite son swing.

La base habituelle : les pieds écartés à peu près de la largeur des épaules ; pour un droitier, le pied gauche légèrement en avant (un gaucher fait l'inverse) ; les genoux souples, pas bloqués ; le poids légèrement vers l'avant, environ 60 % sur le pied avant. Les moniteurs anglophones disent « nose over toes » (le nez au-dessus des orteils).

La consigne clé : orienter le pied avant vers le point de casse, l'endroit où le tireur prévoit de casser le plateau. Le corps est alors à l'aise, « déroulé », exactement là où le tir a lieu. Le tireur pivote depuis les hanches pour revenir vers le point d'attente des canons, puis se déroule dans le tir. Si les pieds font face au lanceur, préviennent les moniteurs, le corps arrive en bout de rotation : le fusil s'arrête ou la tête se lève.

Le corps pivote depuis les hanches, pas avec les bras. Les pieds peuvent être placés un peu différemment pour chaque plateau.

Traduisez « front foot » et « back foot » par pied avant et pied arrière, et non par gauche et droite : votre tireur est peut-être gaucher.

L'essentiel
  • Sporting™ : les deux pieds dans le poste de 1 m avant d'appeler le plateau.
  • Compak® Sporting : pas de tir de 1 m avec limiteur d'angle de tir.
  • Pieds à la largeur des épaules, genoux souples, poids légèrement vers l'avant.
  • Le pied avant vise le point de casse ; on pivote depuis les hanches pour revenir au point d'attente.
  • Traduisez pied avant / pied arrière, pas gauche / droite.

Le moniteur dit

“Point your front foot at the break point.”
Tournez la pointe du pied avant vers l'endroit où le plateau sera cassé.
Pointez votre pied avant vers le point de casse.
“Set your feet for the break, then wind back to the hold.”
Placez d'abord les pieds pour le point de casse, puis faites pivoter le haut du corps vers le point d'attente des canons.
Placez vos pieds pour la casse, puis revenez en arrière jusqu'au point d'attente.
“Weight forward, soft knees.”
Penchez-vous légèrement sur le pied avant et ne bloquez pas les genoux.
Le poids vers l'avant, les genoux souples.
“Turn from the hips, not the arms.”
Tout le haut du corps pivote ; les bras ne font pas bouger le fusil tout seuls.
Pivotez avec les hanches, pas avec les bras.

Testez-vous

Vers où le moniteur veut-il généralement que le pied avant soit orienté ?
  1. Vers le lanceur
  2. Vers le point de prise
  3. Vers l'arbitre
  4. Vers le point de casse
Exact !

Vers le point de casse — Des pieds placés pour le point de casse laissent le corps à l'aise là où le tir a lieu ; des pieds tournés vers le lanceur font arriver le corps en bout de rotation.

Qu'exige le règlement du Parcours de Chasse – Sporting™ pour les pieds avant l'appel du plateau ?
  1. Les deux pieds à l'intérieur du poste
  2. Le pied avant sur la ligne du poste
  3. Les pieds joints
  4. Aucune exigence
Exact !

Les deux pieds à l'intérieur du poste — La règle de la position d'attente demande que les deux pieds soient à l'intérieur du poste de tir de 1 m avant que le tireur appelle le plateau.

Un tireur gaucher. Le moniteur dit « Open your front foot ». De quel pied s'agit-il ?
  1. Toujours le gauche, quelle que soit la main
  2. Le droit : c'est le pied avant d'un gaucher
  3. Le pied arrière, plus proche du lanceur
  4. Les deux pieds ensemble
Exact !

Le droit : c'est le pied avant d'un gaucher — Pour un gaucher, le pied avant est le droit. Traduire « front foot » par « pied avant » évite l'erreur.
