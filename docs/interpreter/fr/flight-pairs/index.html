Simples et doublés : coup de fusil, rafale, simultané

Un plateau simple (single) est un plateau issu d'un seul lanceur. Dans les deux disciplines, on peut le tirer de deux coups : un manqué peut donc être rattrapé avec le second coup. Un doublé (pair, double) se compose de deux plateaux tirés comme une seule unité après un seul appel.

Doublé coup de fusil (report pair, double on report) : l'appel lance le premier plateau, et le coup tiré sur lui lance le second. En Parcours de Chasse – Sporting™, le second part de 0 à 3 secondes après ce coup. L'ordre est imposé. « Report » désigne le bruit du coup de feu, pas un rapport écrit.

Le doublé que la FITASC appelle rafale (following pair) : deux plateaux du même lanceur sur la même trajectoire, le second aussi vite que le lanceur se recharge ; on peut tirer l'un ou l'autre en premier. Il n'existe qu'en Sporting™ : un doublé de Compak® Sporting est soit coup de fusil, soit simultané.

Doublé simultané (« simo » ; en Sporting anglais « true pair ») : les deux plateaux partent au même instant, d'un ou deux lanceurs (en Compak® Sporting, toujours de deux lanceurs différents), et peuvent être tirés dans n'importe quel ordre.

Cartouches : en Sporting™, il y en a deux pour le doublé et les deux peuvent être tirées sur un même plateau ; si un seul coup casse les deux, les deux comptent. En Compak® Sporting, une seule cartouche par plateau est autorisée, et deux coups sur un même plateau donnent zéro-zéro ; un seul coup qui casse les deux plateaux n'est pas non plus simplement compté deux fois (la mission Compak® l'explique).

Sur un poste de Sporting™, la planche tire d'abord les plateaux simples, puis les doublés. Les doublés simultanés et les rafales sont montrés avant le tir ; les doublés coup de fusil ne le sont pas.

L'essentiel
  • Plateau simple : un plateau, deux coups autorisés.
  • Doublé coup de fusil : le coup sur le premier lance le second ; ordre imposé.
  • Rafale (following pair) : même lanceur, même trajectoire, en Sporting™ uniquement.
  • Simultané (true pair) : les deux à la fois, dans n'importe quel ordre.
  • Sporting™ : les deux cartouches peuvent aller sur un même plateau ; Compak® Sporting : une par plateau.

Le moniteur dit

“It's on report — finish the first one properly, the second waits for your shot.”
Le second plateau ne part que lorsque le tireur tire sur le premier : inutile donc de précipiter le premier.
C'est un coup de fusil : finissez bien le premier, le second attend votre coup.
“Simo: take the rabbit first, the teal will wait for you.”
Dans le doublé simultané, tirez d'abord le rabbit, car la chandelle (teal) reste plus longtemps en l'air.
Simultané : prenez d'abord le rabbit, la chandelle vous attendra.
“Rafale — after the first, come straight back to the trap for the second.”
Les deux plateaux viennent du même lanceur ; après le premier coup, ramenez les yeux et le fusil vers le lanceur pour prendre le second.
Rafale : après le premier, revenez tout de suite vers le lanceur pour le second.
“True pair from the tower, five of them.”
Cinq doublés simultanés lancés depuis la tour (formulation du Sporting anglais).
Doublés simultanés depuis la tour, cinq.

Testez-vous

Dans un doublé coup de fusil, qu'est-ce qui lance le second plateau ?
  1. Un second appel
  2. Le signal de l'arbitre
  3. Le coup tiré sur le premier plateau
  4. Une minuterie d'exactement 5 secondes
Exact !

Le coup tiré sur le premier plateau — « On report » signifie au bruit du coup de feu : tirer sur le premier plateau lance le second.

Un tireur tire ses deux cartouches sur le premier plateau d'un doublé simultané en Compak® Sporting. Résultat ?
  1. Autorisé, comme en Sporting™
  2. Zéro-zéro
  3. No bird et répétition
  4. Seul le second plateau est zéro
Exact !

Zéro-zéro — Le Compak® Sporting autorise une cartouche par plateau d'un doublé ; tirer volontairement les deux sur un même plateau donne zéro-zéro. En Sporting™, ce serait autorisé.

Un moniteur britannique dit « true pair ». Comment le traduisez-vous ?
  1. Un doublé correct, régulier
  2. Un doublé de vrais oiseaux
  3. Une rafale
  4. Un doublé simultané
Exact !

Un doublé simultané — « True pair » est le nom du doublé simultané dans le Sporting anglais ; « true » n'a rien à voir avec la régularité.
