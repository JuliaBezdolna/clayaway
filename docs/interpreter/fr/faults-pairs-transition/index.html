Les doublés : le second plateau

Sur un doublé (pair, double), beaucoup de tireurs cassent le premier plateau et manquent le second. Le moniteur parle alors de transition, le passage du premier plateau au second, et de récupération (recovery), la reprise du contrôle du fusil et de la tête après le premier coup.

La règle d'or est « eyes first, then the gun » : les yeux d'abord, ensuite le fusil. Les yeux quittent le premier plateau cassé et trouvent le second ; le fusil suit. Un tireur qui regarde le premier plateau casser, ou qui fait pivoter le fusil avant d'avoir trouvé le second, perd du temps. Les moniteurs disent « eyes to the second » (les yeux sur le second) ou montrent simplement du doigt.

La récupération : le recul relève les canons et parfois la tête. « Let the gun recover, then go » signifie : la joue de nouveau en place et le fusil de nouveau sur la ligne avant d'aller chercher le second plateau. Une bonne position, le poids vers l'avant, accélère la récupération.

La préparation : en lisant le doublé, le moniteur décide quel plateau prendre en premier et où le casser pour que le second soit facile à prendre. Phrases typiques : « take the dropping one first » (prenez d'abord celui qui descend), « break the first early » (cassez le premier tôt), « stick to the plan » (tenez-vous au plan). Un tireur qui change l'ordre sur le poste « went for the wrong one » (est parti sur le mauvais).

Le règlement compte ici. En Parcours de Chasse – Sporting™, la position du fusil est libre entre les deux plateaux de tout doublé, et le tireur dispose de deux cartouches pour un doublé, qui peuvent toutes deux être tirées sur le même plateau. En Compak® Sporting, une seule cartouche par plateau est autorisée dans un doublé. N'expliquez pas vous-même les pénalités : traduisez le moniteur et laissez les questions de règlement à l'arbitre.

L'essentiel
  • Les yeux d'abord, ensuite le fusil.
  • Récupération : la joue de nouveau sur la crosse et le fusil sur la ligne avant le second plateau.
  • Le moniteur prévoit l'ordre et les points de casse d'un doublé en le lisant.
  • Sporting™ : position du fusil libre entre les plateaux, et les deux cartouches peuvent être tirées sur un même plateau ; Compak® Sporting : une cartouche par plateau.

Le moniteur dit

“Eyes first to the second bird, then the gun.”
Trouvez le second plateau avec les yeux avant de bouger le fusil.
Les yeux d'abord sur le second plateau, ensuite le fusil.
“Let the gun recover, then go to the second.”
Après le recul, replacez le fusil et la joue avant le second coup.
Laissez le fusil récupérer, puis allez sur le second.
“Take the dropping one first.”
Tirez d'abord le plateau qui va disparaître ou tomber le plus tôt.
Prenez d'abord celui qui descend.
“Don't watch the first one break.”
Passez immédiatement les yeux sur le second plateau.
Ne regardez pas casser le premier.
“You went for the wrong one first, stick to the plan.”
Le tireur a changé l'ordre prévu ; c'est une remarque technique, pas une infraction au règlement.
Vous êtes d'abord parti sur le mauvais, tenez-vous au plan.
