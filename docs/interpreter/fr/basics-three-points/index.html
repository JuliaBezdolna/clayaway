Point de prise, point d'attente et point de casse : préparer un poste

Avant chaque plateau, le tireur fixe trois points. Le point de prise (pick-up point) est l'endroit où les yeux voient le plateau nettement pour la première fois, un peu au-delà du lanceur plutôt qu'à sa sortie, où le plateau n'est qu'une traînée floue. Le point d'attente des canons (hold point) est l'endroit où les canons attendent au moment de l'appel, en général sur la ligne du plateau ou juste en dessous, entre le point de prise et le point de casse. Le point de casse (break point) est l'endroit où le tireur prévoit de casser le plateau.

L'ordre de préparation : choisir d'abord le point de casse, y orienter les pieds, revenir en pivotant jusqu'au point d'attente, puis poser les yeux sur le point de prise. En Parcours de Chasse – Sporting™, la crosse reste basse jusqu'à l'apparition du plateau ; le point d'attente y désigne donc l'endroit où pointent les canons pendant que le fusil est bas.

Les erreurs typiques : un point de casse trop lointain donne un swing rapide et mal contrôlé, ou un plateau qui retombe déjà ; trop proche, il y a trop peu de mouvement et le tireur « pique » (poke). Un point d'attente trop près du lanceur oblige le fusil à courir après le plateau ; trop loin, le plateau dépasse le fusil.

On lit les plateaux pendant la présentation. En Sporting™, toutes les trajectoires sont montrées au premier tireur et, sur demande, l'arbitre répète la présentation, jusqu'à deux plateaux pour chaque plateau du menu ; en Compak® Sporting par planches, les plateaux simples sont montrés une seule fois le matin, pour la première planche. Le plateau doit être cassé là où l'arbitre peut le voir, à l'intérieur de la limite de tir.

« Where are you taking it? » demande le point de casse ; « kill point » en est un synonyme neutre.

L'essentiel
  • Point de prise = les yeux ; point d'attente = les canons ; point de casse = là où le plateau est cassé.
  • On prépare à rebours depuis le point de casse : pieds, point d'attente, yeux.
  • Le point d'attente se situe en général entre prise et casse, sur la ligne ou juste en dessous.
  • On lit les plateaux pendant la présentation ; on les casse là où l'arbitre peut les voir.
  • « Where are you taking it? » = où est votre point de casse ?

Le moniteur dit

“Where are you taking it?”
Le moniteur demande où le tireur prévoit de casser le plateau.
Vous le prenez où ?
“Move your hold point halfway back to the trap.”
Tenez les canons plus près du lanceur, à la moitié de la distance actuelle.
Ramenez votre point d'attente à mi-chemin du lanceur.
“Look further out — pick it up where it's sharp.”
Éloignez les yeux du lanceur, vers l'endroit où l'on voit le plateau nettement pour la première fois.
Regardez plus loin : prenez-le là où il est net.
“Hold a little lower, just under the line.”
Gardez les canons légèrement sous la trajectoire du plateau au moment de l'appel.
Attendez un peu plus bas, juste sous la ligne.

Testez-vous

Quel point concerne les yeux et non le fusil ?
  1. Le point d'attente
  2. Le point de casse
  3. Le point de prise
  4. Le point d'insertion
Exact !

Le point de prise — Le point de prise est l'endroit où les yeux voient le plateau nettement pour la première fois ; le point d'attente concerne les canons.

Que se passe-t-il généralement si le point d'attente est trop près du lanceur ?
  1. Le plateau dépasse le fusil
  2. L'arbitre annonce No bird
  3. Le fusil doit courir après le plateau
  4. Le plateau ralentit
Exact !

Le fusil doit courir après le plateau — Trop près du lanceur, le plateau passe devant les canons à pleine vitesse et le tireur doit lui courir après.

En Parcours de Chasse – Sporting™, le tireur au poste demande à revoir la présentation. Quel est le maximum par plateau du menu ?
  1. Deux plateaux
  2. Aucun : la répétition n'est pas autorisée
  3. Autant qu'il le souhaite
  4. Exactement cinq
Exact !

Deux plateaux — L'arbitre répète la présentation sur demande, jusqu'à un maximum de deux plateaux pour chaque plateau du menu.
