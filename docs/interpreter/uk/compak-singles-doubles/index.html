Одиночні мішені й дуплети в Compak®

Compak® Sporting вживає ті самі слова, що й Parcours de Chasse – Sporting™, але дуплети тут підпорядковані іншим правилам. Перекладач, який переносить сюди правила Sporting™, дасть хибні відповіді.

Одиночні мішені: кожна має давати змогу на два постріли з кожного з п’яти місць, тож другий ствол — законний другий шанс.

Правила Compak® визначають два види дуплетів: за пострілом (on report: команда запускає першу мішень, постріл — другу; одна чи дві машинки) і одночасний (simultaneous: дві мішені на одну команду, завжди з двох різних машинок, порядок довільний). Rafale тут немає.

Головна відмінність: на дуплеті Compak® по кожній мішені можна випустити лише один патрон. Стріляти обома пострілами по першій мішені заборонено, а довідник для суддів оцінює навмисний подвійний постріл по одній мішені як zero і zero. У Sporting™ обидва патрони можна випустити по одній мішені.

Дві мішені одним пострілом: на дуплеті on report результат першої зберігають, друга — No Bird, і дуплет стріляють знову. На simultaneous — No Bird, нічого не зараховують, дуплет повторюють; удруге так само; утретє — zero і zero. У Sporting™ такий постріл дає просто one і one.

Нерегулярні мішені: якщо нерегулярна перша мішень дуплета on report або будь-яка мішень simultaneous, запускають новий дуплет. Якщо друга мішень дуплета on report нерегулярна чи її розбила перша, результат першої зберігають, а дуплет повторюють.

Головне
  • Лише два види дуплетів: on report і simultaneous; rafale немає.
  • На дуплеті — один патрон на мішень; обидва по одній — zero і zero (довідник суддів).
  • On report, дві одним пострілом: результат першої зберігають, друга — No Bird, дуплет повторюють.
  • Simultaneous, дві одним пострілом: двічі No Bird, утретє — zero і zero.
