Plateaux

Midi

Définition

Plateau plus petit que le standard, de 90 mm de diamètre.

En détail

Le midi est un plateau spécial autorisé dans les deux disciplines. En Parcours de Chasse, le menu affiché devant le poste doit l'indiquer comme plateau de 90 mm, pour que le tireur sache ce qui l'attend. Un plateau de mauvaise taille sorti de la machine est un No Bird.
