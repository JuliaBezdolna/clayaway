    Shooting limit (limite de tir)

    Définition

    Limite au-delà de laquelle un plateau cassé ne compte pas.

    En détail

    C'est au tireur de casser les plateaux là où l'arbitre peut les voir. Si l'arbitre estime qu'un plateau a été tiré derrière un obstacle naturel ou au-delà d'une limite de tir, cette décision est sans appel. Le résumé du Parcours de Chasse ne précise pas comment les limites sont matérialisées ; cela est fixé pour chaque parcours.
