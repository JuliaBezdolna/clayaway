ClayAway

Définition

Le service de ClayArena pour les tours d'entraînement organisés avec un entraîneur.

En détail

ClayAway est la partie de ClayArena dans laquelle un entraîneur ou un organisateur réunit un groupe de tireurs pour un tour d'entraînement, et le tireur achète un seul forfait. Le forfait peut comprendre l'entraînement sur des stands de tir, l'hébergement, les transferts, un programme commun et, si besoin, un interprète. L'organisateur peut être l'entraîneur, mais aussi un club, un stand ou une agence. Les tours portent le nom de l'entraîneur ou du lieu, suivi du format, par exemple « <nom de l'entraîneur> Training Week ». Les horaires du programme d'un tour sont donnés dans le fuseau horaire du lieu, avec l'indication du fuseau, et les règles d'entrée d'un fusil et de cartouches dans le pays du tour doivent être vérifiées à l'avance.
