Red card

So sagt man: Rote Karte

Was es ist

Eine Karte für einen wiederholten Verstoß nach einer Verwarnung, wobei die Scheibe als Strafe gewertet wird.

Ausführlich

Nach der ersten Verwarnung führt jeder weitere Verstoß auf demselben Layout (Sporting) oder Compak zu einer Roten Karte. Die Scheibe wird dann gewertet: Null bei einer Einzelscheibe; Null und No Bird bei einer Doublette auf Schuss; Null und Null bei einer Simultan- oder Rafale-Doublette. Bei einer Compak-Störung auf die zweite Scheibe einer Doublette bleibt das erste Ergebnis bestehen, die zweite ist Null. Im Compak ergibt auch ein zweiter Vorfall gleicher Art mit Flinte oder Munition Null mit Roter Karte.
