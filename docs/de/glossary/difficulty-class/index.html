Difficulty class (Schwierigkeitsklasse)

Was es ist

Die Einstufung einer Sporting-Flugbahn danach, wie viele Scheiben ein durchschnittlicher Schütze trifft.

Ausführlich

Klasse A bedeutet mehr als 80 % Treffer, Klasse B 60 % bis 80 %, Klasse C 40 % bis 60 %. Die empfohlene Mischung für einen Stand ist eine A-, zwei B- und eine C-Flugbahn; eine fünfte Einzelscheibe darf nur Klasse A oder B sein. Bei Doubletten darf eine Flugbahn der Klasse C nur einmal pro Stand vorkommen, idealerweise mit einer A; eine Doublette kann B + B oder B + A sein.
