Abfolgen und Doubletten

Single target

So sagt man: Einzelscheibe

Was es ist

Eine Scheibe aus einer Maschine, auf die der Schütze zwei Patronen abgeben darf.

Ausführlich

Eine Einzelscheibe kann jeder Scheibentyp sein. Jede Einzelscheibe muss genug Zeit für zwei Schüsse lassen, damit bei einem Fehlschuss mit dem ersten Lauf der zweite genutzt werden kann. Im Sporting hat jedes Layout 15 Einzelscheiben, und an jedem Stand schießt die Rotte zuerst die Einzelscheiben und dann die Doubletten, sofern die Jury nichts anderes festlegt. Im Compak kann eine Position 5 Einzelscheiben, 3 Einzelscheiben und eine Doublette oder 1 Einzelscheibe und zwei Doubletten haben.

In Sporting™ und Compak® Sporting

Sporting™

15 Einzelscheiben pro Layout; erst Einzelscheiben, dann Doubletten.

Compak® Sporting

Pro Position: 5 Einzelscheiben / 3 + eine Doublette / 1 + zwei Doubletten.
