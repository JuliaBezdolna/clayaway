Hunting ethics

So sagt man: Jagdliche Ethik (Waidgerechtigkeit)

Was es ist

Der Grundsatz, dass Sporting-Scheiben auf Entfernungen geworfen werden, auf die ein echter Jäger schießen würde.

Ausführlich

Sporting-Layouts müssen die jagdliche Ethik beachten. Eine Scheibe darf nicht so nah sein, dass echtes Wild zerschossen würde, und nicht so weit, dass ein echtes Tier nur verletzt würde, also jenseits der wirksamen Reichweite von Flinte und Patrone. Jede Einzelscheibe muss genug Zeit für zwei Schüsse lassen. Parcoursbauer und Jury wenden diesen Grundsatz an, wenn sie Flugbahnen einstellen und prüfen.
