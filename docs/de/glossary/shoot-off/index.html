Shoot-off

So sagt man: Stechen

Was es ist

Eine zusätzliche Serie zur Entscheidung von Gleichständen um die ersten drei Plätze.

Ausführlich

Nur Gleichstände um die ersten drei Einzelplätze (im Compak auch in jeder Klasse) werden durch ein Stechen entschieden. Es ist eine Serie von 25 Scheiben; besteht der Gleichstand weiter, wird eine zweite Stufe als Sudden Death geschossen. Für das Stechen gelten die normalen Regeln, freie Rottenplätze werden aber nicht aufgefüllt. Wurde keine Zeit im Voraus festgelegt, müssen die Schützen mit der Jury in Kontakt bleiben und innerhalb von 15 Minuten nach dem Aufruf bereit sein; wer fehlt, wird disqualifiziert oder als zurückgetreten behandelt. Die Jury kann es aus außergewöhnlichen Gründen auf den nächsten Tag verschieben. Mannschaften haben nie ein Stechen.

In Sporting™ und Compak® Sporting

Sporting™

Auf einem neuen, von der Jury festgelegten Layout, wenn die Zeit es erlaubt.

Compak® Sporting

Auf einem Compak mit 1 Einzelscheibe und 2 Simultandoubletten pro Position, gewählt von der Technischen Kommission oder der Jury.
