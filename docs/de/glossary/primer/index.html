Primer

So sagt man: Zündhütchen

Was es ist

Eine kleine Kapsel im Hülsenboden, die beim Aufschlag des Schlagbolzens zündet und das Pulver entflammt.

Ausführlich

Das Zündhütchen sitzt in der Mitte des Metallbodens der Hülse. Trifft der Schlagbolzen der Flinte darauf, flammt der Zündsatz auf, und die Flamme entzündet die Pulverladung. Ein schwaches oder träges Zündhütchen kann einen Versager oder einen Nachbrenner verursachen. Deshalb wird die Flinte nach einem Versagen nicht sofort geöffnet: Sie bleibt in eine sichere Richtung gerichtet, bis der Schiedsrichter sie geprüft hat. Eine Delle im Zündhütchen ohne Schuss ist ein typisches Zeichen für eine fehlerhafte Patrone oder einen schwachen Schlagbolzenaufschlag.
