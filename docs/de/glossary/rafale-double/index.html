Abfolgen und Doubletten

Rafale double

So sagt man: Rafale-Doublette

Was es ist

Eine Sporting-Doublette aus zwei Scheiben derselben Maschine auf derselben Flugbahn, kurz nacheinander.

Ausführlich

Bei einer Rafale-Doublette folgt die zweite Scheibe so schnell, wie der Maschinenarm nachlädt, und jede der beiden darf zuerst beschossen werden. Sie wird bei der Scheibenvorführung gezeigt wie eine Simultandoublette. Bei Strafen und Störungen wird sie wie eine Simultandoublette behandelt: Eine irreguläre Scheibe bedeutet Wiederholung der Doublette ohne Wertung, eine Rote-Karte-Strafe bedeutet Null und Null. An einer Position mit 3 Maschinen und 2 Doubletten können die Doubletten simultan, Rafale oder beides sein.

In Sporting™ und Compak® Sporting

Sporting™

Nur Sporting; die Compak-Regeln kennen keine Rafale-Doublette.
