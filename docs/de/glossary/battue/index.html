Wurfscheiben

Battue

Was es ist

Eine dünne, flache Scheibe, die hochkant fliegt, sich dreht und schnell abfällt.

Ausführlich

Battue ist eine der Spezialscheiben, die sowohl im Sporting als auch im Compak erlaubt sind; sie muss auf dem Wurfplan angegeben sein. Ihr dünnes Profil macht sie im Flug schwer zu lesen. Die Compak-Regeln raten von Battue-Scheiben auf sehr kurzen Flugbahnen ab.

In Sporting™ und Compak® Sporting

Sporting™

Muss auf dem Wurfplan des Standes stehen.

Compak® Sporting

Auf sehr kurzen Flugbahnen nicht empfohlen.
