Wertung

Zero

So sagt man: Null (Fehler)

Was es ist

Eine Scheibe, die nach den Regeln als verfehlt oder verloren gewertet wird.

Ausführlich

Eine Scheibe ist eine Null, wenn kein sichtbares Stück abbricht oder nur Staub oder Rauch erscheint. Sie ist auch eine Null, wenn der Schütze ohne triftigen Grund nicht auf eine korrekte Scheibe schießt, die Flinte öffnet oder die Sicherung berührt, bevor der Schiedsrichter eine Störung prüft, oder einen zweiten Vorfall mit Flinte oder Munition in derselben Serie hat. Null ist auch das übliche Strafergebnis bei wiederholten Verstößen (Rote Karte). Auf Schießzetteln wird ein Fehler mit O markiert, und im Compak sagt der Schiedsrichter jede Null laut oder per Tonsignal an, damit der Schütze sofort protestieren kann.

In Sporting™ und Compak® Sporting

Sporting™

Ein verspäteter Schütze, der seinen Durchgang verpasst hat, erhält Null für jede nicht geschossene Scheibe.

Compak® Sporting

Ankunft nach dem ersten Abruf der Rotte: 25 Nullen für die Serie.
