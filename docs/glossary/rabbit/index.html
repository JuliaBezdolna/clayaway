Targets

Rabbit

Також: Rabbit target, Running rabbit

Що це

Товста міцна мішень, що котиться землею, імітуючи зайця.

A thick, strong target rolled along the ground to imitate a running rabbit.

Детально

Rabbit дозволена в обох дисциплінах; у Sporting її вказують у меню. Як і по всіх мішенях, по rabbit стріляють лише з рушницею, приставленою до плеча; стрільба «від стегна» заборонена. Обидва правила мають особливий випадок No Bird: якщо rabbit не влучили першим пострілом і вона сама розбилася до другого, її запускають знову, і на повторі зараховують лише влучання другим пострілом; розбита першим пострілом — zero.

Rabbits are allowed in both disciplines and must be shown on the Sporting menu. In Sporting they, like all targets, must be shot with the gun mounted; firing from the hip is not allowed. A special No Bird case applies in both rulebooks: if a rabbit is missed with the first shot and then breaks by itself before the second shot, it is thrown again, and on the repeat only a break with the second shot counts; a first-shot break scores zero.
