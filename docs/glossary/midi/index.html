Targets

Midi

Також: 90 mm target

Що це

Мішень менша за стандартну, діаметром 90 мм.

A target smaller than the standard one, 90 mm in diameter.

Детально

Midi — спеціальна мішень, дозволена в обох дисциплінах. У Sporting меню перед місцем має позначати її як 90 мм, щоб стрілець знав, що полетить. Мішень неправильного розміру — No Bird.

Midi is a special target allowed in both disciplines. In Sporting the menu in front of the stand must show it as a 90 mm target so the shooter knows what is coming. A wrong size from the machine is a No Bird.
