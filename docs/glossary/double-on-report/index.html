Double on report

Також: Report pair, On report

Що це

Дуплет, у якому друга мішень вилітає на звук пострілу по першій.

Детально

Мішені летять з однієї або двох машинок: команда запускає першу, а постріл по першій — другу. У Sporting друга мішень вилітає через 0–3 секунди після першого пострілу. Під час показу в Sporting дуплети on report не показують, а на місці з 3 машинками і 2 дуплетами не може бути двох дуплетів on report. У sudden death Sporting дуплет on report рахують як пару, тож one-zero дорівнює zero-one. Покарання на такому дуплеті зазвичай — zero на першій мішені й No Bird на другій.

У Sporting і Compak

Sporting™

Не показують перед стрільбою; у sudden death one-zero = zero-one.

Compak® Sporting

Якщо один набій розбив обидві мішені, результат першої фіксують, друга — No Bird, дуплет повторюють; новому стрільцю на місці 1 показують першу мішень дуплету.

Як кажуть українською

«дуплет на постріл», «репорт»
