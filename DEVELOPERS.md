# ClayAway — нотатки для програмістів

Це **проєкт** нового напряму ClayArena, зібраний як статичний сайт для обговорення і передачі в розробку.
Усе тут — робоча специфікація + працюючі макети. Далі програмісти переносять це в ClayArena (backend, БД,
адмінка, авторизація, платежі). Цей файл пояснює, що є що, як воно працює і що треба зробити для продакшену.

> Мова коду й даних — англійська (ідентифікатори, ключі). Тексти інтерфейсу — лише 11 мов сайту ClayArena (en uk de fr it cs pl pt hu fi lt); інших мов не додаємо.
> Повні ТЗ: `docs/concept/` (тури ClayAway) і `docs/rules-spec/` (правила FITASC, тренажер, глосарій, SEO, легальність).

## 2. Як запустити локально

```bash
python -m http.server 8791 --bind 127.0.0.1 --directory docs
```
Відкрити http://127.0.0.1:8791/ . Збірки: `bun scripts/build_seo.mjs` (разом з Академією, §4f), `python scripts/make_og.py`, `python scripts/seo_meta.py`.
Порядок після зміни даних правил, глосарія чи уроків: `build_seo.mjs` → `make_og.py` → `seo_meta.py` (повна пересборка: `bun scripts/build_seo.mjs && python scripts/make_og.py && python scripts/seo_meta.py`).
Пробні збірки — лише в тимчасову теку (`--out <тека>`) або `bun scripts/build_academy.mjs --check` (лише перевірки); `scripts/build_interpreter*.py` у пересборку не входять (виведено з ужитку, §4a).

## 3. Тури ClayAway → ClayArena

Сторінки `docs/dornsberg|sologne/index.html` — один файл = HTML + CSS + JS. Дані туру зараз у константах JS
(`TOURS`, `MEDIA`, `GLANCE`, `MEALS`, `MEALPHOTOS`); у продакшені це відповіді API. Відповідність:

| Константа в макеті | Сутність / таблиця в ClayArena (див. ТЗ «Сутності й поля») |
|---|---|
| `TOURS[t]` (title, dates, places, booked, min, price, options, langs, about, program, included, cancel, faq…) | `Tour`, `PriceOption`, `ItineraryDay`, `ItineraryItem`, переклади полів по мовах туру |
| `TOURS[t].people` | `TourMember` (ролі: Organizer, Coach, Staff:Interpreter…) + профілі ClayArena (тренер, стрілець, стенд) |
| `TOURS[t].qa` | публічні питання (відкрита зона спілкування), модерація |
| `TOURS[t].announcements`, `chat` | закрита зона групи — **через існуючі інструменти спілкування ClayArena** |
| `TOURS[t].participants`, `todo`, `inbox` | `Booking`, `Payment`, задачі кабінету організатора |
| `MEDIA` | медіа туру: відео ClayArena (cdn.clayarena.com), фото, embed соцмереж |
| `GLANCE` | блок «The tour at a glance»: спорт / трансфер / кухня / ≤50 км / готель |
| `MEALS`, `MEALPHOTOS` | `ItineraryItem(type=meal)` з `meal_kind`, `included`, `together`, `venue`, `cuisine_note` |

Обов’язково на сервері (у макеті імітується в браузері):
- **Місця**: утримання місця 15 хв під час оплати (транзакція/lock), лічильник вільних місць, лист очікування.
- **Доступ**: закрита зона групи тільки для підтверджених оплачених бронювань; видимість полів за роллю перевіряє сервер.
- **Оплата**: через ClayArena, split-платежі (наприклад Stripe Connect), комісія ClayArena — % від виплати організатору.
- **Мови**: кожне текстове поле туру — окремо на кожній увімкненій мові; EN обов’язкова.
- **SEO**: див. ТЗ турів, розділ «SEO, розмітка і прев’ю» (Event + Offer JSON-LD, OG-картинка з обкладинки).

## 4. Довідник правил і тренажер → ClayArena

- Дані: `docs/rules/data/sporting.js`, `compak.js` (книга → розділи → пункти → FAQ), `quiz-*.js` (питання з `refs` на пункти).
  У БД: `rule_books`, `rule_sections`, `rule_items`, `rule_faq`, `rule_quiz_questions`, `glossary_terms`; поле `edition` для версій.
- Пошук зараз — клієнтський (TF-IDF-подібний, словник синонімів UA/EN у `docs/rules/index.html`, функції `expand`, `search`).
  Етап 2: `POST /api/rules/ask` → пошук пунктів на сервері → Claude API відповідає **лише** з цих пунктів, з `ref`/сторінками.
- Тренажер: прогрес у `localStorage` `clayarena-trainer` (лише назви ClayArena, аудит R-02; старий ключ попередньої назви читається один раз
  для перенесення) → у продакшені в профілі користувача (+ бейдж, статистика складних питань). Режими: швидкий тест (10, пояснення одразу),
  **короткий тест** (10 питань, результат у кінці, прохідний бал 80 % — вимога маршруту «Перші змагання»; `stats[disc].short_best`, `short_at`),
  іспит (30, 80 %; `stats[disc].best`), мої помилки. Академія лише **читає** ці результати (`docs/shared/progress.js`, `trainerPass`):
  короткий тест або іспит зараховують вимогу маршруту з `mode: "short"`, XP і значки «Іспит з правил …» — лише іспит.
  Відкритий з Академії (`?lang=<l>&from=learn[&mode=short]`) тренажер показує «← Академія» (на сторінку Академії, з якої прийшли, якщо вона
  тією самою мовою; інакше на головну Академії цією мовою або англійською, якщо її ще не опубліковано — `ClayNav.link`), пропонує короткий
  тест першим, а зміна мови оновлює `?lang` в адресі (оновлення сторінки чи надіслане посилання лишаються тією мовою).
- **Навігація тренажера** (рішення власника 07.10.2026, §4i): тренажер — частина Практики Академії, не окремий пункт панелі. Шапка — крихти
  «🎓 Академія › Практика › Тренажер правил» (назви з `ClayNav.link`/`name`), панель підсвічує «Академія». Мова: `?lang` > мова відвідувача >
  останній вибір тут > браузер; вибір мови записує мову відвідувача. Під час тесту — рядок «← Академія» (`from=learn`) або «← Правила FITASC» ·
  режим · дисципліна · n/N · «прогрес збережено». Кнопка «Перервати тест» питає «Зберегти й вийти» (тест лишається 24 год у
  `clayarena-trainer-run`, екран режимів показує «Незавершений тест … Продовжити») / «Скинути» / «Продовжити тест». Незавершений тест
  відкривається одразу, лише коли адреса не просить іншого (`?mode`, `#дисципліна`); інакше екран режимів показує його поруч із запитаним режимом.
  `?mode=mistakes#<дисципліна>` (підказка панелі «Помилок для повторення … (Compak® Sporting): N») одразу запускає «Мої помилки».
  У довіднику — помітна кнопка «🎯 Тренажер правил →» з `?lang` мовою відвідувача.
- Оновлення FITASC: GitHub Action → задача → оновлення даних → погодження суддею → `fitasc_check.py --accept`.

## 4a. Академія перекладача → ClayArena (історія; тепер маршрут «Перекладач» Академії, §4d–4f)

> `scripts/build_interpreter.py` і `build_interpreter_pages.py` **виведено з ужитку**: файли лишено як довідку до перемикання, `build_seo.mjs`
> від них не залежить, а `build_interpreter.py` без `--legacy` не запускається (інакше переписав би `docs/interpreter/` і `docs/shared/sims-text.js`).

- Майстер-контент: `docs/interpreter/src/missions/*.json` (кожне текстове поле `{en, uk}`), `ui.json`, `terms.json` (терміни 11 мовами з `conf` і `src`), переклади `src/i18n/<lang>.json`.
  Збірка: `python scripts/build_interpreter.py` → `data/<lang>.js` (одна мова на файл, поле за полем запасна англійська) і `data/terms.js`.
- У БД: `missions`, `lessons` (перекладні поля), `coach_phrases`, `quiz_items`, `terms` + `term_translations` (term, alt, note, confidence, source_url).
- Прогрес, XP, іспит і сертифікат зараз у `localStorage` (`clayarena-interpreter`) → у продакшені профіль користувача, іспит перевіряє сервер, сертифікат з перевірним ID; позначка в профілі перекладача ClayAway.
- Симуляції (`flightSim`, `leadLab` в `docs/interpreter/index.html`) — canvas без бібліотек; фізика навчальна (див. ТЗ правил, розділ «Маршрут «Перекладач»», `docs/rules-spec/#interpreter`).
- Озвучення фраз тренера — Web Speech API (`en-GB`), без зовнішніх сервісів; у продакшені можна замінити записами носіїв.

## 4b. Спільні модулі і єдині дані (без дублювання)

- `docs/shared/nav.js` — панель проєктів ClayArena на кожній сторінці (додає `scripts/build_seo.mjs`): **єдина таблиця назв** розділів 11 мовами,
  мова відвідувача, колір і значок розділу, «шлях назад» (`ClayNav.setResume({section, label, url})` / `ClayNav.clearResume(section)`),
  персональні підказки з `localStorage`, «Перейти до змісту». Повністю — §4i.
- `docs/shared/sims.js` — анімації (траєкторії, дуплети, лабораторія виносу, сцени на стрілецькому місці: команда й виліт, положення рушниці,
  осічка, вкладка) і `TERM_SIMS` (термін → анімація); `ClaySims.auto()` монтує `[data-clay-sim]` / `[data-clay-term]` на статичних сторінках;
  `ClaySpeak(text)` — вимова англійською (Web Speech API). Тексти й назви термінів — `docs/shared/sims-text.js` (`CLAYSIMS_TEXT`, `CLAYSIMS_TERMS`).
  **Сторінки підключають `docs/shared/sims.min.js`** — мінімізовану копію `sims.js`, яку пише кожна збірка (`minifySims()` у `build_academy.mjs`;
  ≈ 78 КБ, gzip ≈ 29 КБ замість ≈ 165 КБ з коментарями; малює піксель у піксель так само). Джерело одне — `sims.js` (коментарі для команди):
  правити лише його й перезібрати, `.min`-файл не редагувати. `build_seo.mjs` переводить на `.min` і рукописні сторінки (`docs/learn/index.html`,
  тренажер правил).
  Поведінка (аудит анімацій 10.2026): кнопка ▶ під час показу стає ⏹ «Зупинити» (WCAG 2.2.2), потім ↻ «Ще раз»; автозапуск — один раз, коли на
  екрані половина полотна (або 60 % висоти вікна для високого), ніколи з `prefers-reduced-motion` і ніколи після першої дії читача всередині
  анімації (клік, повзунок, список); на вузькому екрані текст і позначки на полотні малюються більшими (`fit()`), годинник сцен — у смузі над
  сценою, полотно не вище 70 % вікна; терміни на полотні й слова тренера — англійською (стендові слова), решта — мовою сторінки (SCHEMA.md §8).
  **Безпека в анімаціях (рішення власника 08.10.2026, жорстке правило):** перед стрілецьким місцем ніхто не стоїть, поки можлива стрільба.
  У сценах на стрілецькому місці суддя й оператор машинки стоять позаду стрільця; машинка внизу поля — у будиночку за захисним щитом, людей
  там немає; оператор запускає мішень кнопкою в руці (кабель по землі до будиночка), звуковий сигнал судді йде назад до оператора; сонопул —
  мікрофон на передньому краї стрілецького місця (не перед ним), без оператора; стволи ніколи не спрямовані на людей. З рушницею біля плеча
  (Compak® Sporting) стволи чекають у точці утримання і не опускаються до будиночка машинки, а йдуть за мішенню, лише коли вона піднялася
  до цієї висоти; після осічки стволи опущені в поле, до землі перед місцем. Нерозбита мішень падає в поле перед місцем і ніколи не летить
  на стрільця (у траєкторіях «Dropping target» і «Chandelle» так само: вони кінчаються біля лінії дерев, а не біля стрільця). Усі люди
  в сценах (стрілець, суддя, оператор, провідник собаки) — у стрілецьких окулярах і навушниках (`protection()`), як вимагають уроки про захист
  очей і слуху; собака — у собачих навушниках, позаду місця, на повідку. `person()` не дає намалювати людину перед місцем (переносить її назад
  і пише попередження в консоль), `dog()` так само тримає собаку позаду. Після зміни сцени, пози рушниці чи траєкторії `TP` перевіряти покадрово
  (кожні 1/60 с): люди й собака лише позаду, ані лінія пози, ані намальований канал стволів не перетинають людей і собаку, з рушницею біля плеча
  стволи до пострілу дивляться вгору, мішень не залітає на місце. Докладно — коментар SAFETY над `SCENES` у `sims.js`.
  **Вигляд анімацій (стиль 10.2026; схвалено власником 08.10.2026: «вечірнє поле» — концепт A з доповненнями з B і C; блок `ART` у `sims.js`).**
  Один колір — одне значення: помаранчевий — лише мішень (її слід-«комета», уламки, пунктирний «привид» у момент рішення); м’ятний — лінія
  польоту (крапки) і стрілка напрямку; бірюзовий — стволи (позначка стволів, точка утримання, лінія прицілу, сліди стволів, кільце осипу дробу,
  звуковий сигнал судді); бурштиновий — увага й очі (лінія на жилеті, рішення, точка підхоплення, м’який і жорсткий фокус, «щока на гребені» —
  підсвітка верхнього краю гребеня, а не кільце: кільце обводило лінзу й перекривало навушник, а захист має бути видно, — лінзи окулярів); смарагдовий — підказка й «добре» (виніс, точка розбиття, «вчасно», імпульс запуску); червоний — помилка. Фіолетовий не
  вживаємо: на сайті це колір Compak® Sporting. У небі — жодних зірок і цяток: ніщо не має бути схожим на мішень. Без паралаксу й руху камери.
  Полотно малює в логічних одиницях 720 × 380 (лабораторія — 720 × 300); `fit()` ставить буфер = логічний розмір × `devicePixelRatio` (не більше 2),
  тож на телефонах чітко, а всі числа сцен ті самі. Статичне тло (небо, пагорби, дерева, трава, місце, будиночок машинки із земляним валом)
  малюється один раз у позаекранне полотно (`layer()`, до 6 штук) і копіюється одним `drawImage`; так само люди, які в цьому кадрі не рухаються
  (провідник собаки, оператор, суддя, поки стоїть, собака, поки сидить тихо), — спрайти за станом (`sprite()`; той самий малюнок); усе випадкове —
  із зерном (`rng`), тож кожен показ і кожна заставка однакові. Кожне слово на полотні — на темній «пігулці» (`label()`); на телефоні назви точок самі шукають вільне місце
  (`placeLabel()`), у лабораторії «рішення» відсувається від «пострілу», а значення виносу — з лінії вогню.
  Люди — реальних пропорцій (суддя 174 см, оператор 170, провідник собаки 168); у всіх кепка, стрілецькі окуляри й навушники, навмисно трохи
  більші за справжні (бурштинові лінзи, темні чашки зі смарагдовим обідком) — навчальний акцент, не помилка. Рушниця — лише вертикалка
  (переломна), ніколи не напівавтомат; закрита лише на стрілецькому місці, коли черга стрільця (після осічки лишається закритою, стволи в поле,
  доки суддя не перевірить, — правильно); поза місцем рушницю малюємо переломленою й порожньою (`gun(…, {open: true})`; зараз такої сцени немає).
  Поза рушниці `{hx, hy, th}` — точка затильника в «кишені» плеча (4 см нижче п’ятки приклада) і кут стволів: цю лінію рахують перевірки безпеки,
  а намальований канал стволів іде паралельно на `BORE` = 8,5 px вище. Голова стрільця нерухома: під час вкладки рушниця приходить до обличчя
  (гребінь торкається щоки, ≤ 3 px). Лінія на жилеті червоніє, коли намальована п’ятка приклада вище за неї до вильоту мішені.
  Вид з-за місця (траєкторії, дуплети, лабораторія): стрілець зі спини внизу посередині, рушниця готова в точці утримання (з «points» — вкладена
  за позначкою стволів); стволи вкорочені в перспективі. Лабораторія показує сліди стволів через рівні 0,05 с (швидка рушниця — далеко один від
  одного, засідка — купкою), «привид» мішені в момент рішення, хмару дробу від стволів і кільце осипу в точці зустрічі поверх уламків
  (влучання = мішень у кільці). У лабораторії з «зайцем» місця на фоні немає (заєць котиться там, де були б його стійки): рушниця входить знизу
  кадру як рушниця глядача, з рукою на цівці. Зі спини вертикалку видно з планкою зверху (без темної лінії посередині — то була б горизонталка).
  Маскот: у кожній сцені на стрілецькому місці собака сидить позаду місця на повідку біля провідника (без рушниці, в окулярах і навушниках),

  Автоматичних переходів за мовою браузера немає (це відправило б пошуковиків геть з українських сторінок): бажану мову пропонує банер.
  Мова бажання: мова відвідувача сайту (`clayarena-lang`, §4i; її пише й перемикач Академії) → стан → мова браузера.
  Вибір мови в шапці змінює сторінку лише на підтверджений вибір: мишею чи пальцем — одразу; з клавіатури стрілки лише рухаються списком,
  перехід — Enter або кнопка «→», що з’являється (аудит ia-code-22). Так само працює вибір мови тренажера правил (`#tlang`, кнопка `#tlangGo`).
  **Хлібні крихти уроку — за тим, звідки прийшли:** сторінка маршруту, картка «Продовжити», «Далі» і смуга кроків додають `?route=<id>`
  (тоді «Академія › <маршрут> › Етап n › <урок>», смуга кроків і «Далі» — маршруту); без нього — шлях за темою «Академія › <тема> › <розділ> ›
  <урок>» (ті самі рівні, що в статичних сторінках `build_academy.mjs`), а поточний маршрут пристрою — лише чипом «Також у маршруті «…»: крок n з m».
  Canonical ніколи не містить `?route`.
  Старі хеш-посилання головної (`/learn/#<id уроку>`, `/learn/#<модуль>`) розв’язує `learn/data/id-map.json`.
- **Урок.** Усі типи блоків: `p`, `h` (підзаголовок розділу уроку `<h2>` з якорем: `anchor` — старий id влитого уроку, інакше ключ `k`;
  якорі не ховаються під липкою шапкою), `steps`, `tip`, `warn` (помаранчева рамка), `compare` (колонки Sporting™ | Compak® Sporting з обов’язковими
  підписами), `rule` (дисципліна + посилання в довідник з `?lang`), `law` (таблиця закону в межах свого блоку, без горизонтальної прокрутки сторінки),
  `fact`, `evidence` (значок «Добре досліджено / Є дослідження / Мало досліджень / Досвід тренерів» біля абзацу), `sim` (анімація уроку великим
  блоком одразу після першого абзацу, на телефоні — перед ним, після опису; заголовок «▶ …», ▶ / ⏹ / ↻, 🐢, рядок «на що дивитися»; у рядку
  метаданих посилання «▶ з анімацією»; програється сама один раз, коли видно, і не перезапускається після відповіді в тесті чи власного запуску
  читача; якщо дані уроку не завантажились, статична сторінка лишається, а анімацію монтує `staticSims()`; без JS порожній блок прихований),
  `figure` (лише медіа ClayArena). Блоки іншої дисципліни згортаються, не зникають («Моя дисципліна»).
  Позначки «Перевіряється» (`review_flag`), «Урок оновлено» (пройдено старий `rev`), «Не є медичною порадою», «ClayAway готується» (`preview`, noindex).
  Панель «Мова стенду» (англійська фраза з 🔊 — **лише голос, що працює на пристрої**, аудит W-08) і нотатки «Для перекладача» розкриті
  на маршруті «Перекладач» (`notes_open`), «Мова стенду» — ще й у блоці «Мова стенду». Терміни ведуть на сторінки глосарія мовою сторінки,
  правила — у довідник (noindex, `?lang`), FITASC — `rel="nofollow noopener noreferrer"`. Тест: 3 питання, варіанти перемішуються, відповідь
  зберігається за ключем варіанта. «Далі» — за поточним маршрутом (інакше за порядком блоків). «Повідомити про помилку» — контакти ClayArena.
- **Практика.** Лабораторія виносу і «Назви траєкторію» (`sims.js`), «Зрозумійте / перекладіть тренера» (режими «зрозуміти» і «перекласти»,

  фільтр дисципліни, noindex), картки термінів (коробки Лейтнера на пристрої, терміни пройдених уроків із глосарія), розмовник (друк, теж з `phrases.json`),

  Картки термінів — той самий запис: `items` = id карток сесії (12), `k` — поточна картка, `flip` — картку перевернуто, `own` — терміни з
  пройдених уроків; після «Сторінка в глосарії →» і повернення сесія продовжується з тієї самої картки (коробки й дати карток — окремо, `S.cards`).
- **XP, рівні, значки** (`levels.json`, `badges.json`, дизайн §7.7) рахує `ClayProgress.computeXP()` заново з прогресу (нічого не рахується двічі,
  ніколи не менше `xp_floor`): урок уперше 20 + 10 за правильну відповідь (до 50), пізніше 3 з 3 — +10 раз, нова версія уроку — +5 раз,
  гра — 5 за відповідь (до 50 на день на гру), етап +25, блок +50, іспит маршруту від 80 % +150, «Іспит з правил» від 80 % +50 на дисципліну.
  Серій і таблиць лідерів немає. Сертифікат: обов’язкові уроки + іспит маршруту + практика маршруту; аркуш A4 для друку з ім’ям (лише на пристрої),
  датою, балом, місцевим номером і рядком «не є кваліфікацією…». У продакшені — номер із сервера й посилання для перевірки.
- **Перенесення прогресу** (дизайн §7.8, `ClayProgress.migrate`, один раз на пристрої, безпечно повторювати): `clayarena-learn` і `clayarena-interpreter`
  проходять через `id-map.json`, один урок з обох — один раз із найкращим балом, `rev: 0` («Урок оновлено»), старий XP → `xp_floor`,

  `interpreter` → `learn`; старі ключі не змінюються (6 місяців на відкат). Новий ключ — `clayarena-academy`; підсумок поточного маршруту
  (`nav`) читає підказка панелі `nav.js`. Кожне звернення до сховища — у try/catch; якщо сховище закрите, застосунок працює в пам’яті й каже про це.
  «Перенести прогрес» на `/learn/progress/`: код `1.<base64url deflate>` лише в хеші (`#import=…`), без імені; злиття — правило максимуму.
- **Мови.** 11 мов ClayArena, перемикач у шапці й список мов у підвалі (та сама сторінка іншою мовою; урок, якого там немає, відкриває свою тему).
  Рядки інтерфейсу — `content/academy/ui/<lang>.json` (нові ключі поки en + uk, решта мов бере англійську до хвиль перекладу).
- **`nav.js`.** Один пункт «Академія»: `/learn/` або `/<lang>/learn/` — **лише якщо Академію цією мовою опубліковано** за списком
  `learn/data/languages.json`, який пише збірка (`published`); інакше `/en/learn/` (з `hreflang="en"`). Список читається лише для мов, крім uk/en,
  раз за сесію браузера (`sessionStorage` `clayarena-learn-langs`); поки його немає або файл недоступний — uk → `/learn/`, решта → `/en/learn/`
  (ніколи не вгадана сторінка, якої може не бути). Підказка «Продовжте маршрут «…»: N з M»; пункту «Академія перекладача» немає,

  `&from=learn`. Для сторінок: `ClayNav.link(id, lang)`
  (посилання панелі мовою `lang`) і подія `claynav:update` після кожного перемальовування (так тренажер оновлює свій «← Академія»).

- **Перевірка.** Тести Bun для `progress.js` і переадресатора (міграція, XP, значки, сертифікати, перенесення, закрите сховище, усі старі id × 11 мов,
  короткий тест тренажера проти іспиту) і перевірка в браузері на тимчасовій збірці `build_academy.mjs --out <тека> --draft --base http://127.0.0.1:<порт>/`:
  головна, урок із підзаголовками `h`, «Перекладіть тренера» і розмовник (лише `phrases.json`), маршрут «Перші змагання» → тренажер
  `&mode=short` → результат → «← Академія» → вимога виконана; `nav.js` на сторінці мови без Академії веде на `/en/learn/`.

## 4f. Збірка Академії: `scripts/build_academy.mjs`

> ⚠⚠ **Довідник правил FITASC (`/rules/`) і тренажер правил лишаються `noindex`, поза sitemap і `llms.txt`, доки FITASC не дасть письмового дозволу.**
> Перемикач один на весь сайт — `const FITASC_INDEX = false;` на початку `scripts/build_seo.mjs`; `build_academy.mjs` читає його звідти
> (уроки з `index: "fitasc"`, гра «Рішення судді»). Змінює його **лише власник проєкту**. Уроки блоку «Правила» — наші короткі навчальні тексти
> своїми словами (`index: "always"`, індексуються); таблиці штрафів і подробиці — лише в довіднику, на який уроки посилаються.

- **Що робить.** Читає `content/academy/` (а також глосарій `docs/glossary/data/`, дані правил `docs/rules/data/`, реєстр анімацій `docs/shared/sims.js`
  і локальний кеш тексту FITASC `rules/pdf/*.txt`, якого немає в git), перевіряє все за дизайном §6.6 і пише сайт:
  - сторінки уроків `/<p>learn/<id>/`, тем `/<p>learn/topics/<block>/`, маршрутів `/<p>learn/routes/<route>/` (+ `exam/`, noindex), Практики
    `/<p>learn/practice/[<game>/]`, прогресу `/<p>learn/progress/` (noindex) і головні мов (`<p>` = порожньо для uk, `<lang>/` для інших мов);
  - дані застосунку `learn/data/<lang>/catalog.json`, `ui.json`, `phrases.json`, `lessons/<id>.json`, `exams/<route>.json` (формат — `content/academy/SCHEMA.md` §8);
  - `learn/data/languages.json` — мови, якими головна Академії опублікована (`published`; за ним `nav.js` веде на `/<lang>/learn/` або `/en/learn/`);
  - `learn/data/redirects.json` (старі адреси → нові; на clayarena.com — 301) і `learn/data/id-map.json` (для JS-переадресаторів, з `published` по мовах);
  - сторінки-переадресації груп A–D, `sitemap-learn-<lang>.xml`, `og/og-list.json` (картинки для `make_og.py`), `shared/sims-text.js` (тексти анімацій з `ui/<lang>.json`),
    `shared/sims.min.js` (мінімізований `docs/shared/sims.js`, `minifySims()`). Попередження `canvas-word`: `anim_line` довше за 7 літер (на телефоні його
    «пігулка» закриває людей поруч зі стрільцем; німецьке «Markierung» замінено на «Linie»).
- **Запуск.** Зазвичай — разом із сайтом: `bun scripts/build_seo.mjs`. Академія збирається першою; **її помилки зупиняють усю збірку** (нічого не записується).
  Окремо: `bun scripts/build_academy.mjs --check` (лише перевірки) · `--out <тека> --draft` (перегляд разом із чернетками: noindex, позначка «Чернетка»,
  видно блоки `draft` і завдання автору; у `docs/` така збірка не пише) · `--report <файл.json>` (усі знахідки) · `--base http://127.0.0.1:8791/`

- **Звіт.** Консоль показує кількість знахідок за типами: помилки, що зупиняють збірку; помилки уроків-чернеток (не збираються, не зупиняють);

## 4g. Переклади Академії: статуси й правила

- **Мови.** Лише 11 мов сайту ClayArena: en uk de fr it cs pl pt hu fi lt; інших мов (і жодного коду мови поза цими 11) немає ніде — ні в текстах,
  ні в `hreflang`, ні в іменах файлів (збірка зупиняється на мовних помилках: `lang-code`, `lang-words`, `lang-letters` та ін.). Офіційні назви законів у
  `content/academy/laws/<CC>.json` (`law`, `article`) — цитати, їх не перекладають і не перевіряють як текст мови.
- **Хто майстер.** Англійська — майстер-мова і має пріоритет; українська пишеться разом з нею в тому самому файлі `lessons/<id>.json`
  (`h_uk` — хеш англійського тексту, з якого її написано; змінили англійську — попередження `uk-stale`). 9 інших мов — оверлеї
  `content/academy/i18n/<lang>/<id>.json`: тексти за ключем `k` + хеш `h` англійського джерела (перші 8 hex SHA-1, правило — SCHEMA §5).
- **Статус мови уроку:** **ready** — є всі ключі, хеші збігаються; **stale** — англійський текст змінився після перекладу (`overlay-stale`);
  **incomplete** — бракує ключів. Ключ оверлею, якого вже немає в майстрі, — `overlay-orphan` (перенести або прибрати).
- **Коли сторінка мовою X публікується:** є назва уроку в оверлеї і **всі** елементи з `core: true` перекладено й не застаріли. Тоді сторінка є в
  hreflang, `catalog.json` X має `status: "published"`. Неперекладені абзаци без `core` не показуються — унизу «Ще N абзаців — англійською» з
  посиланням на en. Застарілий абзац уроку з `critical` (безпека, правила, антидопінг) показується **англійською** з позначкою «Переклад оновлюється»;
  інші застарілі абзаци лишаються в старому перекладі з попередженням. Інакше урок мовою X має статус `untranslated` (без файлу, `alt` — мови, де він є)
  і **ніколи** не переадресовується на іншу мову.
- **Головна, теми, маршрути й Практика мовою X** з’являються, коли є `i18n/<X>/_shared.json` (назви блоків, розділів, маршрутів, етапів, ігор,
  рівнів, значків; попередження `shared-missing`). Тоді збірка вносить X у `learn/data/languages.json` → `published`, і пункт «Академія» панелі
  `nav.js` веде на `/<X>/learn/`; до того — на `/en/learn/`.
- **Рядки інтерфейсу** — `content/academy/ui/<lang>.json` (публікуються як `learn/data/<lang>/ui.json`); бракує рядка — береться англійська з
  попередженням `ui-fallback` (список — `ui_fallback` у `ui.json`). Нові ключі спершу додаються в en + uk, решта мов — у хвилях перекладу.
- **Порядок роботи:** спершу виправлення аудиту в майстрі (en + uk), потім оновлення 9 оверлеїв — щоб хибний факт не розійшовся 9 мовами.
  Перекладати з **поточної** англійської; копіювати хеш `h` без нового перекладу не можна.
- **Українська термінологія:** вкладка (gun mount), заєць (rabbit, рішення власника 07.10.2026), дуплет, точка пострілу, точка підхоплення, точка утримання (hold point), провідне око (master eye),
  передпостріловий ритуал, стрілецьке місце (у Compak® Sporting — номер), імітація стрільби, Європейський вогнепальний паспорт, підгонка рушниці,
  наважка (load weight, як в офіційному перекладі правил), шушотаж (chuchotage); апостроф — ’. Слова «squad» не вживаємо (у ClayArena це інше).
- **Де дивитися стан:** `bun scripts/build_academy.mjs --check` (кількість сторінок кожною мовою, `overlay-stale`, `overlay-orphan`, `ui-fallback`,
  `shared-missing`) або `--report <файл.json>` (усі знахідки з мовою й уроком).

## 4h. Власна статистика відвідувань: `docs/shared/stats.js` + `tools/stats/`

Анонімна статистика відвідувань без cookies і без IP-адрес; дані у власній таблиці власника проєкту (Google Sheets);
посилання на панель статистики ніде не публікується. Сторонніх сервісів аналітики немає. Налаштування для власника — `tools/stats/README.md`.

- **Трекер** `docs/shared/stats.js` (ES2018, без залежностей, < 6 КБ; тримати так). Підключається одним динамічним `<script>` з `docs/shared/nav.js`
  (адреса від кореня сайту, як `ROOT`). Константа `STATS_ENDPOINT` угорі файла: порожня = трекер нічого не робить (жодних запитів і слухачів).
  Не працює при Do Not Track / Global Privacy Control, `navigator.webdriver`, ботах, на `localhost` / `127.0.0.1` / `file:` (для перевірки — `window.CLAY_STATS_DEBUG = true`).
  Без cookies, без localStorage/sessionStorage, без IP, без відбитка: кожен запис окремий.
- **Записи** (JSON-рядок, `text/plain`, `fetch` з `keepalive` і `credentials: "omit"`, запасний варіант — `sendBeacon`):
  `t` view / leave / event · `p` шлях без query і hash (≤ 200) · `s` розділ (learn, glossary, rules, trainer, tours, spec, home, other) ·
  `l` мова сторінки · `bl` мова браузера (2–5 символів) · `tz` часовий пояс · `d` phone / tablet / desktop · `r` лише домен джерела (порожньо для свого сайту) ·
  `e` подія (≤ 40) · `v` значення (≤ 80; у view `"int"` = перехід зі свого сайту чи всередині Академії — не рахується як відвідування) ·
  `sec` секунди видимості з попереднього leave · `sc` максимальна прокрутка % (лише в першому leave перегляду).
  Перехід усередині Академії (`history.pushState`, «назад») = leave старої адреси + view нової.
- **Події** (назви зберегти й у продакшені): `route` (id маршруту), `lesson_done` (id уроку, вперше), `quiz` (`урок:бал/кількість`),
  `game_start` (id гри), `game_end` (`гра:правильно/питань` або id), `exam_pass` / `exam_fail` (`маршрут:бал`), `cert` (маршрут),
  `lang` (нова мова; Академія і тренажер), `disc` (sporting / compak / both), `trainer_test` (`дисципліна:режим:%`),
  `lead` (`метод:hit|behind|ahead|none`, лише «Ваша черга»), `speak` (термін чи фраза, `ClaySpeak`). Виклик завжди безпечний:
  `const stat = (n, v) => { try { if (window.ClayStats) window.ClayStats.event(n, v); } catch (e) {} };`
- **Збирач і панель** `tools/stats/Code.gs` + `Dashboard.html` (Google Apps Script, прив’язаний до таблиці): `doPost` перевіряє кожне поле за білим списком,
  відкидає запити > 2 КБ, дописує рядок `[час сервера ISO, t, p, s, l, bl, tz, d, r, e, v, sec, sc]` в аркуш `hits` під `LockService`;
  денний ліміт `CFG.DAILY_CAP` — календарна доба за часовим поясом скрипта, рахується за рядками самої таблиці (`countSince_`, лише стовпець A);
  `CacheService` тільки запам’ятовує це число (його записи живуть ≤ 6 год і можуть зникнути раніше — тоді просто перерахунок, ліміт не скидається;
  не `PropertiesService`: його денна квота читань/записів менша за два виклики на запис);
  `doGet` показує панель лише власнику (`Session.getActiveUser()` = `getEffectiveUser()`), іншим — текст `ok`; `getStats(days)` — для перемикача періоду;
  `cleanupOldHits()` — видалити рядки старші за `CFG.KEEP_DAYS`. Два розгортання одного скрипта: «Anyone» = адреса збирача (у `STATS_ENDPOINT`),
  «Only myself» = приватна панель. Після зміни коду — нова версія **обох** розгортань (адреси не змінюються).
- **Перевірки** (без мережі й без Google-акаунта): `bun tools/stats/checks/check_tracker.mjs` — трекер з фальшивими window / navigator
  (вимкнений режим, DNT/GPC, боти, localhost, поля й обрізання, leave, переходи в Академії, sendBeacon, ліміт 300 записів);
  `bun tools/stats/checks/check_collector.mjs` — `Code.gs` з макетами `SpreadsheetApp` / `Session` / `ContentService` / `HtmlService` /
  `LockService` / `CacheService` (з TTL ≤ 6 год, витісненням і збоєм) / `Utilities` (валідація, ліміти, денний ліміт через північ за поясом скрипта
  і після закінчення кешу, доступ до панелі, агрегати, екранування, очищення). Запускати після кожної зміни.
- **Обов’язкова перевірка підключення (go / no-go), коли вписуєте чи змінюєте `STATS_ENDPOINT`.** Автоматичної перевірки цього шляху немає:
  `fetch` іде з `mode: "no-cors"`, відповідь непрозора (status 0), тож браузер не відрізняє успіх від втраченого запису. Apps Script на POST
  до `/exec` спершу виконує `doPost`, а потім відповідає редиректом 302 на `script.googleusercontent.com/macros/echo…`, щоб віддати текст `ok`
  (`doGet` при цьому не викликається) — це очікувано. Доказ роботи — лише нові рядки в аркуші `hits`:
  1. збирач: `curl -sL -H 'Content-Type: text/plain' --data '{"t":"event","p":"/stats-check/","s":"other","e":"stats_check","v":"curl"}' "<адреса збирача>"`
     → відповідь `ok` і новий рядок `stats_check` (у панелі — «інші події»; рядок потім можна видалити);
  2. браузер локально (адреса вже в `STATS_ENDPOINT`, `python -m http.server 8791 --bind 127.0.0.1 --directory docs`), у консолі сторінки:
     `window.CLAY_STATS_DEBUG = true; delete window.ClayStats; document.head.appendChild(Object.assign(document.createElement("script"), {src: "/shared/stats.js?debug"}));`
     → рядок `view`, після закриття вкладки — `leave`;
  3. після публікації — крок 5 у `tools/stats/README.md` (рядки `view`, `leave` і `event` із живого сайту).
  Немає рядків на будь-якому кроці — no-go: статистику не вважати робочою, панелі не довіряти, шукати причину (доступ «Anyone», `/exec`, DNT у браузері).
- **Продакшен (clayarena.com):** замінити на аналітику ClayArena за її політикою конфіденційності; назви подій і правило «без персональних даних» зберегти;
  `tools/stats/` не переносити.

## 4j. Маскот Академії: `docs/shared/mascot.js` (рішення власника 08.10.2026)

Жовтий лабрадор у круглому мультяшному стилі — **варіант C** (велика кругла голова, короткі висячі вуха, «видрячий» хвіст, смарагдовий нашийник
з помаранчевим жетоном-мішенню). Ескіз і нотатки конструкції — `design/mascot/sheet.svg`, `notes.md` (не публікуються). Палітра: хутро `#F4C460`,
тінь `#D39338`, крем `#FFEAC0`, контур `#2A1A10`, смарагд `#10B981`, мішень `#FB923C`.

**Правила (жорсткі, перевіряти на рев’ю):**
- **Імені немає** (ще не обрано): ні на малюнках, ні в `title`/`alt`, ні в назвах файлів і коду. Перед запуском — перевірка назви й торговельних марок.
- **Мова:** мовчить або каже лише короткі **англійські** бульбашки зі списку `BUBBLES` — «Good shot!», «Safety first!», «Look!», «Pull!» —
  на кожній мові сторінки (рішення власника: один набір малюнків для 11 мов). Бульбашка — частина малюнка: не перекладається, не є текстом
  інтерфейсу, диктор її не читає. `svg()` і `draw()` ігнорують будь-який інший текст (попередження в консолі). «think» має хмарку «?» (без слів),
  «sleep» — «z z Z».
- **Безпека:** ніколи не тримає й не несе рушницю чи набій (такого малюнка немає — не додавати). Біля стрільби — **позаду стрілецького місця,
  на повідку поруч із провідником** (людина без рушниці, в окулярах і навушниках), у собачих навушниках: вид збоку (`view: "side"`) завжди
  малює навушники; у фронтальних позах — поза «safety» або `muffs: true`. Розставляє людей і собаку в сцені `sims.js` (його правило SAFETY, §4b).
- **Лише декоративно:** `aria-hidden="true"`, `focusable="false"`, ніколи замість тексту (оголошення для диктора будуються без нього — `plainText()`
  в `academy.js`). **Не з’являється** в довіднику правил `/rules/`, у ТЗ `/rules-spec/`, у тренажері правил і в грі «Рішення судді»
  (там лишаємо серйозний тон).
- **Рух:** коротка CSS-поява (стрибок, хвіст, нахил голови, бульбашка — кілька повторів, без нескінченних циклів) лише без
  `prefers-reduced-motion`; на полотні `draw()` малює рівно той стан, який отримала (анімує й зупиняє виклик).

**Підключення.** `nav.js` додає `mascot.js` (async, як `stats.js`) лише на сторінках Академії (крім тренажера), глосарію і 404; сторінка може
відмовитися: `<html data-mascot="off">`. Додати інший розділ — одна умова в `nav.js`. Після завантаження файл заповнює кожен порожній слот
`<span data-clay-mascot="<поза>" data-bubble="Good shot!" data-size="64" data-anim="0" data-side="left" data-flip="1">` на сторінці, а через
`MutationObserver` — і ті, що з’являються пізніше (Академія малює види з JSON), потім подія `claymascot:ready` на `document`.
Без `mascot.js` слот лишається порожнім і не займає місця (`.ac-mascot:empty{display:none}`). Код полотна завжди перевіряє `if (window.ClayMascot)`.

**API `window.ClayMascot`:**
- `POSES` = `["sit", "happy", "think", "point", "safety", "sleep"]`, `BUBBLES`, `PALETTE` (`fur`, `shade`, `cream`, `ink`, `emerald`, `clay`).
- `svg(pose, {size, bubble, anim, side, flip, view, muffs})` → рядок inline SVG. `size` — висота **сидячого** пса в CSS px (типово 96; усі пози
  в тому самому масштабі, SVG росте під бульбашку); менше 64 px — без брів і пальців, більші очі. `bubble` — один із `BUBBLES`; `false` ховає хмарку «think».
  `anim: false` — без руху (той самий стан, намальований знову). `side` — бік бульбашки; `flip` — дзеркально; `view: "side"` — вид збоку.
- `draw(ctx, pose, x, y, scale, state)` → `{head: [x, y], collar: [x, y], top}` у px полотна. `(x, y)` — точка на землі під псом; `scale` 1 ≈ 100 px
  заввишки (у сценах `sims.js` — 0,66: ≈ 66 px, на телефоні ≈ 31 px). З `view: "side"` поза не враховується: вид збоку один (сидить, завжди в навушниках). `state`: `view` (`"side"` для сцен на стрілецькому місці), `flip` (дивиться вліво), `ear` 0..1 (вуха здригаються на «Pull!»),
  `look` — кут голови в радіанах, `atan2(ціль.y − head.y, ціль.x − head.x)` (вид збоку: −40°…+10°; фронтально: очі й невеликий нахил),
  `wag` — фаза хвоста (кут = sin), `blink` 0..1, `muffs`, `bubble`. `collar` — де пристебнути повідець (колір `PALETTE.shade`, другий кінець у руці провідника).
- `mount(el, pose, opts)` → `el`; `mountAll(root)`; `ready`.
- **Дані:** кожна частина тіла — список фігур в одиницях ескізу (початок — центр голови; фронтально голова 132 × 116; збоку земля на y = 157),
  один малюнок для SVG і для полотна: `["P", d, фарба]` контур · `["E", cx, cy, rx, ry, фарба, кут]` · `["C", cx, cy, r, фарба]` ·
  `["R", x, y, w, h, фарба, rx]` · `["T", d, зовн., внутр., колір]` «трубка» (лапи, хвости) · `["L", d, 1|2|товщина, колір]` лінія ·
  `["X", x, y, розмір, текст, колір]` · `["Y", dx, dy]` очі · `["D", [...]]` деталі (зникають < 64 px) ·
  `["G", {t, r: [кут, px, py], s}, [...], ім’я]` група: ім’я = CSS-клас `cm-<ім’я>` для руху і гачок стану полотна (`ear`, `head`, `tail`…).
  Межі поз (`BOX`) виміряні `getBBox()`; після зміни контурів — переміряти.

**Де стоїть (Академія, `docs/learn/app/academy.js`, функції `dog()` / `dogFor()`; стилі `.ac-mascot*` в `academy.css`):**
- тест уроку — біля пояснення **останньої** відповіді: правильно → «happy» + «Good shot!», помилка → «think» (без слів);
- результат іспиту маршруту: склав → «happy» + «Good shot!», ні → «think»;
- Практика: «Назви траєкторію», «Зрозумій / перекладай тренера» (відповідь і кінець раунду, ≥ 80 % → «happy»), «Картки термінів» (кінець — «happy»
  без слів), «Лабораторія виносу» (після кожного влучання «Your turn» — маленький «happy» + «Good shot!» праворуч у рядку результату; наступний
  запуск очищує рядок разом із собакою; не поверх кнопок); **не** в
  «Рішенні судді» і **не** в тренажері правил (`NO_DOG`);
- уроки блоку «Безпека й етикет» (`blocks.json` id `safety`) — угорі «safety» (навушники) + «Safety first!»; нового тексту немає;
- порожні стани: сторінка прогресу без жодного уроку → «sleep»; пошук без результатів → «think»;
- сертифікат маршруту (сторінка маршруту, прогрес, друк) — маленький «happy» у куті;
- `docs/404.html` — «point» + «Look!» біля списку розділів.
Статичні сторінки уроків (`build_academy.mjs`) маскота не мають: він з’являється, коли застосунок перемальовує сторінку.

**Легальність.** Персонаж — власний оригінальний (не схожий на відомих персонажів: без плям, без жетона-кісточки, без людського одягу, без
червоного нашийника). Перед публічним запуском: зворотний пошук зображення, перевірка назви й торговельних марок (коли ім’я оберуть),
зафіксувати авторські права ClayArena на малюнок. У продакшені: той самий `mascot.js` (або SVG-спрайти з тих самих частин), ті самі правила.

## 5. Легальність (коротко; повністю — ТЗ, блок «Легальність контенту і права»)

- Текст і PDF FITASC не публікуємо; лише власний переказ + посилання `rel="nofollow noopener noreferrer"`.
- Фото зі сторонніх сайтів (стенди) — у проєкті тимчасово для внутрішнього показу; перед публічним запуском замінити або отримати дозвіл.
- Фото Wikimedia — з автором і ліцензією в «Photo credits».
- Реальні люди в прикладах — тільки за згодою; демо-тури `noindex`.
- Статистика відвідувань — анонімна, без cookies і без IP-адрес; дані у власній таблиці власника проєкту; посилання на статистику ніде не публікується (§4h).
- Маскот Академії — власний оригінальний персонаж ClayArena; ім’я не обране; перед запуском — зворотний пошук зображення і перевірка назви й торговельних марок (§4j).
